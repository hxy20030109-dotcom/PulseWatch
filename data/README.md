# Dataset instructions

Download the CSV from the official [UCI AI4I 2020 Predictive Maintenance
Dataset](https://archive.ics.uci.edu/dataset/601/ai4i%2B2020%2Bpredictive%2Bmaintenance%2Bda)
page and save it as `data/raw/ai4i2020.csv`. Do not commit the downloaded data.

Please cite: Matzka, S. (2020). *Explainable Artificial Intelligence for
Predictive Maintenance Applications*. AI for Industries.

UCI lists the dataset as CC BY 4.0 and describes it as synthetic. This project
uses it for reproducible experimentation only; it does not establish
performance on real industrial equipment.
